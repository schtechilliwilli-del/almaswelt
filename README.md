# Almas Welt

Interaktive Tablet-Seite für Alma (3 Jahre): Glitzer, Ausmalen, Memorie, Puzzle, Freunde, Puppe anziehen, Bad, Jahreszeiten, Tiere, Autofahren, Wochentage, Zählen, Schreiben, Bildergalerie, Tag und Nacht.

- `index.html`: die fertige Seite, eine einzelne Datei, direkt im Browser zu öffnen
- `src/`: Quellen. `base.html` ist die Grundlage, `new.css`, `new1.js` und `new2.js` die Erweiterungen. `python3 src/build.py` baut daraus wieder `index.html`

Hinweis: Die Bildergalerie speichert nur in der Claude-Artifact-Version dauerhaft. Als einfache Datei bleiben Bilder nur, solange die Seite offen ist.
